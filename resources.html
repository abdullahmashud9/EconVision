Category 03

Econometrics, Code & Free Textbooks

State-of-the-art causal inference guides, open textbooks, and computational toolkits in R, Stata, and Python.

Open Textbook Free Online

Causal Inference: The Mixtape

Scott Cunningham's renowned open textbook covering DAGs, matching, instrument variables, panel fixed effects, DiD, and synthetic control with complete R, Stata, and Python code.

DAGs & Matching Synthetic Control R / Stata / Python
Read The Mixtape Free
Research Design Free Online

The Effect: Research Design & Causality

Nick Huntington-Klein's intuitive guide on identifying causal effects, regression discontinuity, identification strategies, and practical empirical design for social scientists.

Identification RDD & Event Studies Intuitive Math
Read The Effect Book
Computational Econ Python & Julia

QuantEcon (Sargent & Stachurski)

Open-source computational economics courses founded by Nobel Laureate Thomas Sargent. Covers dynamic programming, Markov chains, and macroeconomic modeling in Python and Julia.

Dynamic Programming Python Lectures Macro Modeling
Visit QuantEcon Platform

fixest & did (R Packages)

High-speed multi-way fixed effects estimation (`feols`) and Callaway-Sant'Anna staggered difference-in-differences estimators addressing dynamic treatment effect heterogeneity.

Staggered DiD Fast Multiway FE CRAN Certified
View fixest Documentation

Dynare DSGE Software

Standard software platform used by central banks and academic macroeconomists to solve, simulate, and estimate Dynamic Stochastic General Equilibrium (DSGE) models.

MATLAB / Octave Bayesian Estimation Policy Simulation
Download Dynare Suite
